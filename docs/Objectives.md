# Objectives – Annotation Analytics Assessment

## Main Objective

Build an annotation analytics feature in CVAT that displays the total number of annotations for each class in a selected task.

## Measurable Objectives

1. Create an API endpoint that returns annotation counts grouped by class.
2. Display the API results on a frontend analytics page.
3. Show annotation counts in a graph.
4. Display a clear message when no annotations are available.
5. Display an error message when the API request fails.
6. Measure API response time across five runs.

## Performance Target

Target: API response time under 500 milliseconds for a task containing sample annotations.
